Capture a saved session

capture reads finished turns from Ramabana’s history file. It does not watch a running agent. It writes one session as an Aidialog notebook that Leela can open. The notebook starts with a review note that is skipped when the dialog is replayed, and its metadata holds the session id, the model, the route score and the findings, with status set to review.

All of Dhrona’s notebooks keep their review record under one metadata key, REVIEW_KEY. read_dialog reads a notebook, and clean_dialog returns only its prompt messages, without the review note.

Accept a reviewed round

Accepting is a deliberate step. accept checks that the dialog still converts to chat history and starts with a user turn, then records the reviewer, the source session, the package version and the round revision in the notebook’s metadata. It writes the round’s history as JSON beside the notebook, or at output.

An accepted round also records the tools it calls and the model of its session, so a warm start can check it against the tools on offer. install copies the JSON into the rounds library through install_round. accept still returns the path of the JSON it wrote. To get the library path, call install_round(out, into=...) yourself, which is safe to repeat, or look in ROUNDS_DIR/f'{name}.json'.

from tempfile import TemporaryDirectory
with TemporaryDirectory() as d:
    lib = Path(d)/'lib'
    out = accept(review, reviewer='Karthik', output=Path(d)/'r.json', install=lib)
    meta = out.read_json()['meta']
    assert meta['tools'] == ['web_search'] and 'model' in meta and meta['name'] == 'github'
    assert (lib/'github.json').read_json() == out.read_json()
    again = install_round(out, into=lib)   # the helper `accept(install=)` uses; call it to learn the library path
    assert again == lib/'github.json' and again.read_json() == out.read_json()
    assert install_round(out, into=Path(d)/'other', name='mine') == Path(d)/'other'/'mine.json'

Start a Ramabana session

Ramabana has no command-line option for loading prepared history. start_round therefore sends the accepted round as a first prompt, written by bootstrap_prompt, which ends by asking for the reply DHRONA_READY. Ramabana saves that turn, and a second command resumes the same session for normal work. Without launch, start_round returns the two commands instead of running them.
